# Contratos Android — A2

Modulo Kotlin/JVM puro (sin Android SDK) con los contratos de A2:
`Transport`, `InputSource`, tipos de dominio, mocks y pruebas.

- `src/main/kotlin/com/mandopc/contracts/Contracts.kt`
- `src/main/kotlin/com/mandopc/contracts/Mocks.kt`
- `src/test/kotlin/com/mandopc/contracts/ContractsTest.kt`

Verificacion (requiere Gradle y JDK 17, pendiente de A3):

```
gradle test
```
